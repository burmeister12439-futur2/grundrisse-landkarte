# quellen

Hier liegen Textauszüge einzelner Quellen, damit HAL und Claude sie
prüfen können, ohne den Handapparat zu öffnen.

Regel: Es kommt nur herein, was gebraucht wird. Wer eine Aussage am Text
prüfen will, nennt die Registernummer. Der Auszug wird abgelegt und
bleibt liegen.

Dateiname: `<Nr>_<Kurztitel>.md`, zum Beispiel `169_Beck_Risikogesellschaft.md`.
Im Kopf jeder Datei stehen Registernummer, Titel, Herausgeber, Jahr und
der Pfad im Handapparat.
