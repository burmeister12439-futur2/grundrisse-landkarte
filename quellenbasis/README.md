# quellenbasis

Alles, was als Quelle oder Datengrundlage der GRUNDRISSE dient, liegt
hier. Nichts davon liegt woanders.

| Was | Wo |
|---|---|
| Das Register aller Quellen | `register/` |
| Textauszüge einzelner Quellen | `auszuege/` |
| Wo die Quellen liegen, wie die Basis wächst | `QUELLENBASIS.md` |
| Welche Quelle was belegen darf | `QUELLENSTANDARD.md` |
| Der Prüfer | `pruefe.py` |

Aufruf des Prüfers aus dem Wurzelverzeichnis:

    python3 quellenbasis/pruefe.py

Nicht hier, sondern in `dokumente/`, liegen unsere eigenen
Arbeitsdokumente. Das ist der Unterschied: Hier steht, worauf wir uns
stützen. Dort steht, was wir daraus gemacht haben.

Der Handapparat selbst, rund 6,7 GB, liegt auf Klaus' Rechner unter
`lab-aktuell/Material/Themen`. Er kommt nicht ins Repositorium.
`QUELLENBASIS.md` erklärt, wie man von einer Registerzeile zur Datei
kommt.
